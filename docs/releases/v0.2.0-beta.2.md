# AgentDeck v0.2.0-beta.2 configurable Codex release

这是 ARM64 Android 真机预发布，使用 Android debug 签名，仅用于测试，不是稳定生产包。

## 主要变化

- 产品只使用 App 私有的内嵌 ARM64 Ubuntu/Codex Runtime；移除 Termux 权限、发现、设置和启动流程。
- 首次使用提供 ChatGPT 设备登录、OpenAI API Key 与第三方 Responses 服务三种明确入口，并解释认证文件、`config.toml` 与 Android Keystore 的边界。
- 新增可编辑、校验和持久化的 `agentdeck.config.toml`，内置无必填项说明与常用可选示例，每次会话启动前同步。
- 模型服务区分 Sub2API 预设与通用 Responses；聊天页显示真实 Provider/模型并支持模型选择。
- 设置拆分为模型连接、内嵌 Runtime、对话默认值、Codex 参数和关于页面。
- 对话列表显示最后活动日期时间，并支持搜索、重命名、置顶和归档。
- 每个对话可定义角色名称、身份、目标、表达方式与边界；角色以每轮开发者级指令注入，不伪装成用户消息，恢复旧线程后仍然生效。
- 聊天支持后台继续运行、完成通知、重连、追问排队、模型/权限切换、用户问题表单和文件差异查看。

## 安装与升级

1. 在 ARM64 Android 8.0 或更高版本安装 `AgentDeck-v0.2.0-beta.2-debug.apk`。
2. 已安装 beta.1 的设备可直接覆盖升级；内嵌 Runtime、第三方服务、`config.toml` 和对话记录会保留。
3. 全新安装先准备约 800 MB 的私有 Runtime，再在“设置 -> 模型连接”选择登录方式或添加第三方服务。

## 真机证据

已在 Android 16 / iQOO Neo8（V2301A，ARM64）完成：

- 内嵌 Runtime 安装、启动、升级后持久化和应用重启恢复。

- `agentdeck.config.toml` 以 `0600` 保存并在新会话启动前应用；第三方 API Key 不进入 TOML、Room 或进程参数。

## 已知限制

- 仅提供 ARM64 debug 签名 APK；不是 Play/F-Droid 稳定发行包。
- ChatGPT 设备登录流程已接入官方 app-server 协议，但本轮因手机号验证未做账号端到端验收。
- 仍需扩展更多 OEM/Android 版本、断网、无空间、长任务锁屏和完整审批组合的稳定版矩阵。
