## 本版要点

- 聊天性能第二阶段（P0–P3）：索引化 upsert、页级增量投影、8 页 / 4 MiB 有界窗口、活动虚拟化、空闲会话 LRU、低内存 trim。
- 修复“正在排版回复”卡死：可见集合只由视口 snapshotFlow 写入。
- 会话 handoff 事件串行化，迟到 collector 不能覆盖新会话。
- Runtime 下载看门狗：镜像 20 秒低于约 26 KiB/s 时带 Range 续传并换源。
- Secure 隔离基准界面 + Macrobenchmark 编译门禁；官方数字只认 Secure Beta。

## Secure 边界

- 不提供本地进程 MCP、Hooks 或任意插件 UI。
- 性能窗口只释放 Android 内存，不删除、裁剪或改写 app-server rollout。
- APK 扫描确认不含 `LabLocalMcpRuntimeAdapter`。
