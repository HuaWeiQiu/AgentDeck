# AgentDeck Lab `0.2.0-beta.6-lab`

高权限**实验通道**产物，**不是**日常默认包。请用二手机/可重置设备安装。

## 产物

- `app-lab-arm64-v8a-beta.apk` → `com.agentdeck.app.lab.debug`
- `app-lab-x86_64-beta.apk`

构建：

```bash
cd android && ./gradlew :app:assembleLabBeta
```

## 能力

| 级别 | 内容 | 默认 |
| --- | --- | --- |
| L1 | 本机文件夹（SAF） | 关 |
| L2 | Intent 打开链接 / 分享文本 | 关 |
| L3 | 无障碍屏幕快照 / 按文本点击 | 关 |
| L4 | App UID 白名单 shell（非完整 Shizuku） | 关 |

开启路径：设置 → 会话高级设置 → 开启高级 → 开发者模式 → 我理解风险 → 分项开关。

## 安全边界

- 与 Secure 包 applicationId 分离，可并存
- Secure 编译不含 a11y Service / Lab 执行器实现
- 策略 fail-closed；超通道能力 Denied
- 写操作（含 UI 点击、priv.shell）走审批
- 禁止默认 Root/Magisk；L4 仅白名单探测命令

## 相对 Secure 的修复（本轮）

- 仅开 Lab 能力时也会 bind 宿主会话（不再依赖 L1 工作区）
- `agentdeck-host` 支持 `intent.*` / `ui.*` / `priv.shell`
- Lab 设置与关于页文案缩短
