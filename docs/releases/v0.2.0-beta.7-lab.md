# AgentDeck Lab `0.2.0-beta.7-lab`

高权限**实验通道**产物，**不是**日常默认包。请用二手机/可重置设备安装。

## 产物

- `app-lab-arm64-v8a-beta.apk` → `com.agentdeck.app.lab.debug`
- `app-lab-x86_64-beta.apk`

```bash
cd android && ./gradlew :app:assembleLabBeta
```

版本：`0.2.0-beta.7-lab` · `versionCode=12`（与 secure 同号）

## 能力（相对 secure）

| 级别 | 内容 | 默认 |
| --- | --- | --- |
| L1 | 本机文件夹（SAF） | 关 |
| L2 | Intent 打开链接 / 分享文本 | 关 |
| L3 | 无障碍屏幕快照 / 按文本点击 | 关 |
