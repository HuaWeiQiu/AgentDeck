# AgentDeck v0.1.4 Android runtime test release

This is a prerelease APK signed with the Android debug key. It is intended for device testing, not production distribution.

## What changed

- Native chat now connects directly to the official Codex app-server capability-token WebSocket on `127.0.0.1`; the Python stdio relay has been removed.
- A per-conversation supervisor cleans up only its own PRoot/Codex process tree on disconnect and recovers from an explicit stale active-writer thread.
- Doctor verifies whether Termux can actually finish a background command and links to Android settings when an OEM freezes it.
- Existing CLI Provider/API-key configuration is checked before login prompts, and the chat header shows the Provider/model returned by the running CLI.
- Current Profile pickers were removed because those values were not injected into Codex. Existing database data is retained.
- The composer follows the software keyboard, and reasoning/search/command activity is collapsed into one expandable process row so the final answer remains visually primary.

## Install or update

1. Install F-Droid Termux and enable `allow-external-apps=true` in `~/.termux/termux.properties`.
2. Install `AgentDeck-v0.1.4-debug.apk`. It updates the existing debug build in place.
3. Open AgentDeck, use the action shown by Doctor, and wait until all eight checks are ready.
4. On vivo/iQOO, open Termux app details, choose Battery, then allow background power use. Changing this setting can restart Termux, so close interactive terminal work first.
5. Open a conversation. AgentDeck reuses the Codex CLI authentication and Provider configuration already present inside Ubuntu.

## Device evidence

Verified on Android 16 / iQOO Neo8 (V2301A) with F-Droid Termux 0.119.0 beta:

- Doctor reached 8/8 after Termux background power use was allowed.
- Native chat reported the configured `deepseek` Provider and `deepseek-v4-flash` model.
- Existing thread history restored and a newly sent message received a new assistant response.
- Only one AgentDeck supervisor tree was present while chatting; leaving the page removed its supervisor, PRoot, Node, and Codex processes while retaining the normal Termux app process.

## Known limitations

- The APK uses debug signing and is a prerelease.
- OEM background-process policy differs across devices; more vendors and Android versions still need coverage.
- Fresh Ubuntu/Codex installation, every approval variant, migration from all historical builds, attachments, full diffs, search, and archive/rename flows are not yet fully accepted for a stable release.
