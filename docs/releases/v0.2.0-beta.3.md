# AgentDeck v0.2.0-beta.3 paged chat and attachments

这是 ARM64 Android 真机预发布。APK 使用 Android 测试签名以支持覆盖升级，但不再使用未优化的 Debug 构建；Beta 启用 R8、资源压缩和依赖 Baseline Profile，不是正式签名的稳定生产包。

## 主要变化

- 聊天恢复只取最近 50 轮，滚动到顶部后按 25 轮游标读取更早历史；实时尾部、已加载页和游标只有一个内存状态源。
- Markdown 在后台解析并按顶层块进入同一个 `LazyColumn`；流式文本、输入框和历史状态隔离，快速滚动不再承担整段历史重组。
- 系统文件选择器支持单轮最多 4 个、单个最多 20 MiB 的附件。PNG/JPEG 使用 app-server 原生 `localImage`；其他文件复制进 App 私有 Runtime 后由 Codex 按路径读取。
- 对话标题与模型选择并排显示；页面只有一个模型入口，点当前模型打开可滚动的模型/权限面板，输入区恢复为单行工具栏。
- 返回再打开最近会话时立即显示真实标题和有界的临时首屏预览，后台恢复只占用顶部细进度条，不再显示阻塞式旋转加载画面；预览上限不会删除或限制完整历史。
- 预发布产物改为 R8 优化的 `beta` build type，同时保留原测试签名和 `com.agentdeck.app.debug` application ID，现有 Runtime、模型服务和对话可原位保留。

## 安装与升级

1. 在 ARM64 Android 8.0 或更高版本安装 `AgentDeck-v0.2.0-beta.3-arm64.apk`。
2. 已安装 beta.2 Debug APK 的设备可直接覆盖升级；`versionCode` 从 7 升至 8，私有 Runtime、凭据、配置和对话不会因构建类型变化而迁移或删除。
3. 图片能力取决于模型目录的 `image` modality；明确只支持文本的模型会在发送前拒绝图片。第三方服务未发布能力目录时，由 Provider 对请求做最终校验。

## 已知限制

- 仅提供 ARM64 测试签名 APK；不是 Play/F-Droid 稳定发行包。
- ChatGPT 设备登录流程已接入官方 app-server 协议，但本轮因手机号验证未做账号端到端验收。
- app-server 没有通用原生文件输入；非 PNG/JPEG 文件由 Codex 工具按私有路径读取，实际可解析类型取决于文件内容、当前模型和可用工具。
- 仍需扩展更多 OEM/Android 版本、超长单回复、多页连续历史、断网、无空间和锁屏长任务矩阵。
