## 本版要点

- **会话模式**：对话顶栏左侧选「轻聊 / 开发」；列表只显示当前模式会话。
- **轻聊**：无本机 Agent，Chat Completions + 角色；设置隐藏运行环境/扩展/会话高级。
- **开发**：Codex / pi / dsh 本机 Agent 路径；Runtime 横幅仅在开发模式出现。
- **启动手感**：预热、历史落盘预览、列表按压预取、pi `set_model` 热路径等 P0/P1。
- Runtime 按 CLI 分目录（Codex under `runtimes/codex/`）；dsh / pi 按需安装。
- 菜单背景统一主题 `surface`（模式菜单、会话三点菜单）。

## Secure 边界

- 不含无障碍屏幕代理，也不含本地 MCP。
- 备份文件不含 API Key、Bearer、capability。
- 「狂暴」仅 Lab 包体，不是 Secure 内第三种会话模式。
