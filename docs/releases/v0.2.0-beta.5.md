# AgentDeck v0.2.0-beta.5 国内软件源与安装错误可见预发布

> GitHub Pre-release：修复首次准备在「安装基础工具」阶段因 Ubuntu 官方源/DNS 卡住或失败的问题；ARM64 真机已完成空白数据首次 Runtime 准备验收。x86_64 仍为候选支持。

## 主要变化

- 内嵌 Runtime 安装基础工具时清除 Ubuntu 默认 apt 源，按国内 HTTP 镜像顺序尝试：阿里云 → 清华 → 中科大（arm64 使用 `ubuntu-ports`，x86_64 使用 `ubuntu`）。
- Guest DNS 优先 `223.5.5.5` / `119.29.29.29`，并回退 `8.8.8.8` / `1.1.1.1`；增加 apt 重试与超时配置。
- 准备失败红条展示真实原因（保留可操作摘要），不再只显示笼统“请重试”。
- 第 5 阶段文案标明“通过国内软件源…”，减少进度停在 76% 时的误判。

## 安装影响

- `versionCode` 为 10，`versionName` 为 `0.2.0-beta.5`，包名和测试签名保持不变，可覆盖当前测试版。
- Runtime 内容版本未变（仍为 `ubuntu-24.04.4-codex-0.147.0-r2`）。已成功装好 Runtime 的设备不必重装；首次准备失败或卡在「安装基础工具」的用户建议升级后点「安装或修复」。
- 下方 SHA-256 对应本次 GitHub Pre-release 附件；APK 使用测试签名，不是正式生产签名。

## 已知限制

- Ubuntu Base / Codex 归档仍从 `cdimage.ubuntu.com` 与 GitHub 下载；仅 apt 基础工具阶段切换国内镜像。
- x86_64 仍缺模拟器 Runtime 启动与会话恢复门禁，不能宣称稳定支持。
- 稳定版仍需要更多 OEM、锁屏/进程回收、低空间、长时 soak 和正式签名覆盖。
