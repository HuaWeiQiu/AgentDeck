# AgentDeck v0.1.1 test release

这是用于真实 Android + F-Droid Termux 验收的预发布版本，不是正式签名的稳定版。

## 主要变化

- 修正 Termux `RUN_COMMAND` 命名会话、结构化 argv 和结果回调。
- 加入真实环境 Doctor，检测 Termux、权限、Ubuntu、Codex、登录状态和 wrapper。
- 加入严格版本化配方、依赖排序、安装后验证和固定 SHA-256 校验。
- 完成卡片新建、编辑、启停、删除和兼容 Profile 选择。
- Room v3 使用非破坏迁移，Profile 删除后卡片保留并解除绑定。
- AgentDeck 不再接收、存储或传递 API Key、OAuth token 或 CLI 登录信息。

## 安装

- 需要 Android 8.0（API 26）或更高版本。
- 使用 F-Droid Termux 0.118.3 作为当前测试基线。
- `AgentDeck-v0.1.1-debug.apk` 使用测试签名，不要作为生产发布包分发。
- v0.1.0 debug APK 与本版本签名相同、`versionCode` 更低，可以直接覆盖安装以测试迁移。

APK SHA-256：

```text
808c222e665b83b1e82655c0f7715f55ca60458c5e543936afdd4c91c7edb892
```

## 重点测试

1. 从 v0.1.0 覆盖安装，确认原有卡片和 Profile 保留。
2. 授予 `RUN_COMMAND` 权限并启用 `allow-external-apps=true`。
3. 运行 Doctor，检查每个环境状态和错误信息。
4. 全新安装 Ubuntu 24.04 与 Codex 0.147.0，并完成 `codex login`。
5. 连续打开同一卡片，确认复用同名 Termux 会话。
6. 测试包含空格和引号的工作区路径及 CLI 参数。

完整清单见 [`docs/RELEASE_CHECKLIST.md`](https://github.com/HuaWeiQiu/AgentDeck/blob/v0.1.1/docs/RELEASE_CHECKLIST.md)。反馈问题时请删除日志中的凭据、个人路径和私人数据。

## 已知限制

- 尚未完成真实设备矩阵验收和正式 release 签名。
- Claude Code 仍是不可安装、不可启动的 P1 占位项。
- Profile 当前只做类型约束和本地引用，不会修改 Codex `config.toml`。
- App 不追踪 Termux 会话是否仍在运行。
