## 本版要点

- 设置新增独立“扩展”子页；列表、详情、编辑按需渲染，不挤占设置首页。
- 支持导入严格校验的 `SKILL.md`，按对话选择并在独立 app-server 快照中加载。
- 支持公共 HTTPS MCP、无鉴权或 Bearer、工具发现和 allowlist；工具调用默认逐次询问。
- Bearer 只保存在独立 Android Keystore 密文中，Codex 连接带随机 capability 的本机代理。
- 对话编辑器只提供一个紧凑“扩展”入口；聊天顶栏不增加重复选择器。
- MCP 地址、认证或本地配置可在详情页修改；连接变化后必须重新发现工具。
- 发现结果使用固定高度的独立滚动区域展示工具名称和风险标签，不会随工具数量无限撑高编辑页。
- MCP 审批显示本地扩展名、canonical 工具名和参数；Secure 对未知服务、空 allowlist 或越界工具 fail-closed，审批内容在小屏和大字体下可滚动。
- 支持 v2ray 等 Android VPN 的 RFC 2544 Fake-IP DNS；直填保留/私网地址仍被拒绝。

## Secure 边界

- 不提供本地进程 MCP、Hooks 或任意插件 UI。
- `agentdeck.config.toml` 不允许活动的 `[mcp_servers.*]`。
- 启动前禁用 Codex 全局和项目层中未受 AgentDeck 管理的 MCP；无法读取有效配置时停止连接。
- APK 扫描确认不含 `LabLocalMcpRuntimeAdapter`。

## 真机验证

- Android 16 / Vivo V2301A / ARM64：在 v2ray Fake-IP 模式下发现 DeepWiki 的 3 个工具，固定区域显示并滚动正常；`read_wiki_structure` 弹出 MCP 专用审批，选择“仅允许这次”后得到真实工具结果。
- 强停应用并重新进入同一历史线程后，再次调用仍弹出 MCP 审批并返回真实工具结果；最终 R8 Secure APK 覆盖安装后也通过同一恢复调用。稳定的受管服务 ID 避免恢复时出现 `unsupported call`。启动错误会关闭 required MCP 会话，不会静默退回 web 或 shell。
- Skill 双会话隔离、Bearer 生命周期及泄漏边界由自动化覆盖；本轮真机 MCP 使用无鉴权 DeepWiki，不把自动化结果写成 Bearer 真机证明。
