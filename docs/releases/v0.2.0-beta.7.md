## 本版要点

### 模型选择

- 「验证并获取模型」后展示**全部**可选 model id（不再被当前选中项过滤成只剩一个）。
- 有发现列表时，默认模型 / 会话模型为**只读下拉**，不可手改 ID。
- 仅上游不支持 `/models` 时允许手填模型 ID。

### Runtime 下载源（按出口 IP）

安装前探测网络区域（Cloudflare `cdn-cgi/trace` → ipinfo → locale/时区），缓存 24h：

| 区域 | rootfs / Codex | apt | DNS |
| --- | --- | --- | --- |
| 大陆 `CN` | 国内镜像 / ghfast → 官方 | 阿里/清华/中科大 → Ubuntu 官方 | 223.5… → 8.8/1.1 |
| 海外及其他 | 官方 → 国内镜像 fallback | ports/archive → 国内镜像 | 1.1/8.8 → 国内 DNS |

失败仍按列表 fallback；校验仍为固定 size + SHA-256。

## 构建与通道

- `main` 默认 secure；`channel/secure` / `channel/lab` 与 main 同提交（Lab 仅 flavor 不同）。
- Beta 使用 debug 签名 + `.debug` applicationId，便于覆盖安装开发包。
