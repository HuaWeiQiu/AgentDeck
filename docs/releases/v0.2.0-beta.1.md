# AgentDeck v0.2.0-beta.1 embedded runtime test release

这是 ARM64 Android 真机预发布，使用 Android debug 签名，仅用于测试，不是稳定生产包。

## 主要变化

- 新安装可在 AgentDeck 私有目录一键准备 Ubuntu Base 24.04.4 和 Codex CLI 0.147.0，不再强制安装 Termux。
- 内嵌 PRoot、loader 与 talloc 随 APK 分发；Ubuntu/Codex 下载执行固定大小、SHA-256、安全解包、功能验证和原子启用。
- 首页只保留“对话”和“设置”；聊天支持 Markdown、流式回复、停止、审批、折叠思考/工具过程、键盘避让和最新消息跟随。
- 模型服务支持 Sub2API / OpenAI Responses 模型发现；点“当前 Codex 配置”可把已有 Termux/Ubuntu CLI Provider 导入 Keystore，并自动用于默认 Codex 对话。
- 提供只读、推荐和完全访问三档 Codex 权限；高级设置可切换内嵌 Runtime 或 Termux 兼容模式。
- 内嵌 app-server 由 Android 前台服务、一次性回环 token 和精确进程租约管理；退出对话后会清理完整 PRoot/Codex 进程树。

## 安装与升级

1. 在 ARM64 Android 8.0 或更高版本安装 `AgentDeck-v0.2.0-beta.1-debug.apk`。
2. 全新安装点击“安装或修复”，等待约 122 MB 下载及本机初始化完成；最终私有 Runtime 约占 800 MB。
3. 添加 Responses 兼容模型服务；已有 Termux/Ubuntu Provider 的用户可在“模型服务 → 当前 Codex 配置”一键导入。
4. 回到“对话”并点击 Codex。旧版 debug 安装可覆盖升级，Termux 兼容配置不会被改写或删除。

## 已知限制

- 仅提供 ARM64 debug 签名 APK；不是 Play/F-Droid 稳定发行包。
- 内嵌模式当前以受管 Responses Provider 为完整验收路径；ChatGPT 设备登录仍需后续做成 App 内流程。
- 更多 OEM/Android 版本、无空间、断网、损坏包、重启、回滚、长任务锁屏和所有审批组合仍需稳定版验收。
- Claude Code、附件、完整 diff、会话搜索/归档/重命名尚未交付。
