# AgentDeck v0.1.2 test release

这是 Android 16 真机启动修复后的预发布版本，不是正式签名的稳定版。

## 修复

- 修复新安装首次启动时，默认 Profile 被错误地走“编辑已有 Profile”路径而导致的崩溃。
- 初始化失败现在只记录错误，不再让后台协程异常终止整个 App。
- 新增默认 Profile 数据回归测试。

## 真机验证

- 设备：iQOO Neo8（V2301A）
- 系统：Android 16 / API 36 / arm64
- Termux：0.119.0-beta.3
- 已验证：覆盖安装、首次播种、二次冷启动、`RUN_COMMAND` 系统授权、Termux 外部调用、`proot-distro`、Ubuntu 和 Codex CLI 检测。

## 安装

- 需要 Android 8.0（API 26）或更高版本。
- `AgentDeck-v0.1.2-debug.apk` 使用测试签名，不要作为生产发布包分发。
- 与 v0.1.0/v0.1.1 使用相同 debug 证书，可直接覆盖安装。

APK SHA-256：

```text
5f2a35e66961141713b291dd2a881a9a122a7a8c7efdc5fe3b62f446968fac50
```

安装后请在 Termux 中启用 `allow-external-apps=true`，再回到 AgentDeck 运行 Doctor。完整清单见 [`docs/RELEASE_CHECKLIST.md`](https://github.com/HuaWeiQiu/AgentDeck/blob/v0.1.2/docs/RELEASE_CHECKLIST.md)。

## 已知限制

- 尚未完成从空白 Termux 触发 Ubuntu/Codex 安装，以及 Codex 登录、wrapper 安装和 TUI 启动的完整真机流程。
- Claude Code 仍是不可安装、不可启动的 P1 占位项。
- Profile 当前只做类型约束和本地引用，不会修改 Codex `config.toml`。
